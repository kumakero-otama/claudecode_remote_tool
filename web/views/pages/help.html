このシステムについて

Web アプリから、自宅サーバ上で動く Claude Code に指示を送り、結果を受け取る仕組みです。 公開はしていますが、Google ログイン＋パスキー登録端末でのみ利用できます。

構成図

データの流れ

  1. 端末のブラウザが Funnel(:8443) 経由で web コンテナに接続（Google＋パスキーで認証）。
  2. 「Claude 通信」で送った指示は web → gateway へ。gateway が exec チャネルに積む。
  3. ccrt-worker(exec) が MCP で指示を受け取り、サーバ上で実行 → 結果を gateway 経由・SSE でブラウザへ返す。
  4. 「タスク管理」での編集指示は task チャネルへ。ccrt-worker-task だけが受け取り、tasks/ の .md を編集するだけ。

セキュリティと「実行ロック」

  • 入口：公開URLだが、Google 許可リスト＋パスキー登録端末でないとログインできない。
  • タスクは実行されない：タスク編集は task チャネル の制限ワーカー（Bash/Web 禁止・tasks フォルダ限定）だけが処理。コマンド実行やリポジトリ変更は物理的に不可能で、一覧の記述を整えるだけ。
  • Claude 通信側（exec）はサーバ作業を実行できる強力なチャネル。指示内容に注意。

使い方

  • Claude 通信：指示を送るとサーバ上の Claude が実行して返答。📎 で画像/ファイルを添付（ペースト可）。
  • サーバ情報：CPU・メモリ・ディスク・コンテナ等をリアルタイム表示。
  • タスク管理：タスク一覧の作成・タグ絞り込み。詳細のチャットで「〜を追記」「完了にして」等 → 記述が更新される（作業自体は実行しない）。
  • 端末：右上「端末」から登録端末の確認・解除。
